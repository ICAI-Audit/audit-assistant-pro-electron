# Start here

ICAI VERA is an Electron desktop audit-assistance application with local SQLite storage. Begin each coding session with [AGENTS.md](AGENTS.md), then the [project index](docs/project/README.md), [current status](docs/project/CURRENT_STATUS.md), [next tasks](docs/project/NEXT_TASKS.md), and [latest handoff](docs/project/SESSION_HANDOFF.md).

Use the relevant [project workflow](docs/project/SKILLS_INDEX.md) for the requested change. Read the [development guide](docs/project/DEVELOPMENT_GUIDE.md) before installation or launch; it records the reproduced and repaired lockfile mismatch and the limits of the successful Windows clean-install and native smoke checks.

For a new session, use this instruction:

> Read AGENTS.md and the project index. Check the current branch and working tree, current status, next tasks and latest handoff. State the application architecture, selected task ID, unresolved constraints and validation approach. Continue the requested task, then update the same project records before finishing.

The former updater-specific start page is preserved as [historical updater guidance](docs/UPDATER_START_HERE_LEGACY.md). Its completion claims and setup examples require verification against the current implementation.
