# Financial Statement Review redesign: protected paths

The approved redesign is presentation-only. Do not edit main-process code,
IPC, services, persistence, schemas, calculation helpers, import/export
builders, financial logic or their tests. UI components can contain business
logic: their handlers, state, payloads, validation and calculations are also
protected even when their markup is in scope.

- `electron/` (including `main.cjs`, `preload.cjs`, `fsg/`, and the pre-existing
  untracked development-profile helper and test).
- `sqlite/`, `src/services/`, `src/modules/fsg/api.js`,
  `src/modules/fsg/hooks/`, `src/modules/fsg/utils/`.
- `src/modules/fsg/components/GenerateFinancials/buildExcel.js`,
  `buildHTML.js`, `fillDetailsWorkbook.js`, and
  `src/modules/fsg/components/Notes/manualPyWorkbook.js`.
- Existing tests and their assertions; tests must run unchanged.

captured in the session workspace before UI changes. Compare against that
