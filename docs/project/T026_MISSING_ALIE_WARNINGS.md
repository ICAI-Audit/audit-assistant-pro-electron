## Data and calculation contract

- `financials:getMissingAlie(tbId)` reads every source `tb_rows` record using a left mapping join, including rows with no mapping record. `financials:getConsolidatedMissingAlie(entityId, tbIds)` reads only the explicitly selected TB IDs of that entity; an empty selection means no rows. Existing main-process client/TB permissions protect both read-only channels.
- Resolved ALIE follows the existing financial-data precedence: linked LevelFormat ALIE, mapped ALIE, then the same rule-set/Level 1 lookup used by financials. Null, blank, whitespace or values outside Assets / Equity and Liabilities / Income / Expenses are exceptions. Detection does not depend on mapping status or closing-value materiality.
- Count unique `(tb_id, tb_row_id)` identities. Duplicate ledger names are distinct items. Debit is the sum of absolute negative source closing balances; credit is the sum of positive balances; net is credit minus debit with an explicit Dr/Cr/Nil label. Preserve source signs and current adjusted closing balances; do not change imported or adjusted amounts. Amounts remain in rupees in every warning/list, even when the financial statements use lakhs/crores.
- CY uses the selected current TB's closing values. A separately selected comparative TB uses its own closing values and item count. Without it, PY uses opening balances from the CY TB and is labelled accordingly. PY-off suppresses comparative exceptions only. Consolidated processing uses the same selected CY/PY TB sets as the statements, without netting away missing classifications between branches.
- The warning report is derived afresh, never acknowledged away or saved as a clean flag. A diagnostic read failure shows a red verification-unavailable warning rather than claiming zero exceptions or blocking a draft.

## Visible behavior and information flow

1. The original version attached the report without allocation. The owner subsequently authorised the provisional BS presentation described below; this supersedes the original no-allocation behavior.
2. BS and P&L screens show persistent red bold notices after their heading and after their statement table. Notices cannot be dismissed. A zero net still shows gross debit, credit and item count.
3. The beginning notice expands into a ledger-wise list with CY/PY, branch/TB, stable row ID, name, debit and credit. A real TB can open the existing Rectification workflow scoped to mapped identities. Rows with no mapping record instruct the preparer to run Auto-Mapping first. Consolidated views direct correction to the respective branch TB rather than opening an invalid virtual-TB correction screen.
4. The same notice/list appears on Annexures. PDF prints both notices in red bold on each BS/P&L face, and includes the ledger-wise list with Annexures. Financial Excel places wrapped, merged, bold red warnings at both ends of BS and P&L and adds an `ALIE Exceptions` sheet containing the source figures in rupees. Existing Notes/Annexures and statement formulas remain available.
5. Columnar PDF/Excel carry both notices and branch exception details. The generator now passes the selected current-year TB IDs into branch-data loading, so the warning and columnar financial figures use the same selection; the optional API argument preserves existing callers. Permission checks also cover those TB IDs.
6. Financial snapshots preserve `missing_alie` evidence alongside existing figures. No schema change, migration, source reclassification or external transmission is introduced.
7. Correcting source classifications clears the report on reload. Switching TB/client/year recalculates it for that context; restarting the application cannot dismiss unresolved source exceptions. The warning creates no export/finalisation lock or acknowledgement bypass.

Current example: three missing-ALIE ledgers at Dr 100, Cr 100 and zero produce `2 item(s); Debit 100.00; Credit 100.00; Net 0.00 Nil`. The offsetting nonzero items retain the provisional head; the fully nil item remains in Mapping. A comparative ledger at closing Dr 75/opening Dr 900 produces PY Dr 75 when its TB is selected.
